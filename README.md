# 🌌 우주 지렁이 게임 (Cosmic Snake)

어르신(실버 세대)과 초보자도 쉽게 즐길 수 있도록 제작된 웹 기반의 네온 우주 테마 지렁이 게임입니다.

## ✨ 주요 특징

1. **어르신 맞춤 3가지 직관적 조작 모드**
   - 🖱️ **마우스 따라오기 모드**: 클릭 없이 마우스 커서를 화면 위에 두면 지렁이가 커서를 향해 자동으로 유영합니다.
   - 🎯 **타겟 원클릭 자동 유도**: 먹고 싶은 우주 오브젝트(별, 행성, 보석 등)를 클릭하면 지렁이가 안전하게 자동 비행합니다.
   - 🎛️ **대형 원터치 버튼**: 화면 우측의 큼직한 화살표 버튼을 클릭하거나 터치하여 편하게 조작할 수 있습니다.
   - ⌨️ **기존 키보드 조작**: 방향키(`↑`, `↓`, `←`, `→`) 및 `W`, `A`, `S`, `D`도 함께 지원합니다.

2. **🛡️ 벽 충돌 방지 (안심 워프 시스템)**
   - 벽에 부딪혀서 허무하게 게임 오버가 되지 않도록, 벽에 닿으면 반대편 공간으로 자연스럽게 통과(워프)됩니다.

3. **5가지 우주 목표 타겟**
   - ● 플라즈마 구체 (+1점)
   - ★ 슈퍼스타 (+3점)
   - ◆ 우주 크리스탈 (+2점)
   - ▲ 양자 에너지 워프 (+2점)
   - 🪐 미니 행성 (+2점)

4. **네온 우주 비주얼**
   - 시간에 따라 일렁이는 무지개 네온 오로라 지렁이 바디
   - 지렁이가 지나갈 때마다 방출되는 우주 별가루(Star Dust) 트레일
   - 타겟 획득 시 터지는 고유 색상 파티클 폭발 이펙트
